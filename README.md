# 🌈 HueMory

**A colorful personal mood and memory diary.**

HueMory is an interactive web application for capturing experiences, reflecting on emotions, and revisiting meaningful moments. It combines a playful interface with a private, browser-based diary.

## ✨ Features

- Record memories and select multiple moods
- Reflect using guided prompts
- Add optional photos to entries
- View, edit, and delete saved memories
- Store entries locally using IndexedDB
- Enjoy a colorful interface and original HueMory mascot

## 🛠️ Built with

HTML5 · CSS3 · JavaScript · IndexedDB

## 🚀 Getting started

1. Clone or download this repository.
2. Open `index.html` in a modern browser, or use a local development server such as VS Code Live Server.
3. Start recording memories.

## 🔒 Privacy

Entries are stored locally in your browser. They are not automatically synced between devices. Clearing browser site data may delete them.
